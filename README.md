# DevOps Lab 5–7: API Service, CI/CD and Cloud Deployment

## Лабораторна робота №7: Хмарне розгортання DevOps-сервісу

У цій лабораторній роботі було виконано розгортання API-сервісу у хмарному середовищі Render. Для deployment використано Docker-контейнер, створений на основі проєкту з попередньої лабораторної роботи, де вже був налаштований CI/CD pipeline.

### Використана cloud-платформа

Для хмарного розгортання було обрано платформу Render, оскільки вона підтримує Docker deployment, дозволяє виконати manual deploy з GitHub-репозиторію та надає публічний HTTPS URL для доступу до сервісу.

### Публічний URL сервісу

API-сервіс після розгортання доступний за посиланням:

https://devops-lab7-1.onrender.com

### Перевірка endpoint `/calculate`

Для перевірки роботи сервісу використовується endpoint:

https://devops-lab7-1.onrender.com/calculate

Приклад запиту з параметрами:

https://devops-lab7-1.onrender.com/calculate?a=16.5&Da=0.05&b=4.12&Db=0.005&c=0.198&Dc=0.0005

У результаті сервіс повертає JSON-відповідь з обчисленим значенням функції та оцінкою похибки.

### Підготовка до DevSecOps

Для підготовки сервісу до подальшої перевірки безпеки було виконано такі дії:

* вимкнено debug mode;
* не використовуються паролі або секретні ключі у коді;
* порт запуску сервісу задається через environment variable `PORT`;
* API запускається всередині Docker-контейнера;
* доступ до сервісу здійснюється через HTTPS URL.

### Виконані вимоги лабораторної роботи

* використано проєкт з ЛР6;
* виконано Docker deployment;
* виконано manual deploy на Render;
* отримано публічний HTTPS URL;
* перевірено роботу endpoint `/calculate`;
* сервіс підготовлено до подальшої роботи з DevSecOps.
